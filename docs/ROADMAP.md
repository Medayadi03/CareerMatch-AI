# Roadmap indicative — 30 jours

Chaque étape nécessite validation explicite avant la suivante. Le calendrier est une estimation, pas un engagement de toutes les options.

| Phase | Jours | Résultat et critère de sortie |
| --- | --- | --- |
| 0 | 1–2 | Fondations ; qualité et Compose vérifiés, limitations documentées |
| 1 | 3–6 | Contrats, parsing PDF, preuves paginées, fixtures synthétiques, persistance minimale |
| 2 | 7–10 | Extraction CV/offre structurée, normalisation, validation et tests |
| 3 | 11–15 | Baselines retrieval, matching justifié et score déterministe testé |
| 4 | 16–19 | LangGraph typé, orchestration bornée et comparaison pipeline simple |
| 5 | 20–22 | MCP et une source marché autorisée, dédoublonnage et stats |
| 6 | 23–25 | Recommandations factuelles, roadmap, interface et export |
| 7 | 26–28 | Évaluation indépendante, cache/routing mesurés, confidentialité |
| 8 | 29–30 | Déploiement si autorisé, démonstration et rapport PFE |

Priorité : parcours CV + offre → preuves + lacunes + score. Market Intelligence, optimisations avancées et observabilité complète peuvent être réduits si le planning dérive. Phase 1 autorisée le 25 novembre 2026 pour le parsing PDF local uniquement. La persistance et l'extraction sémantique restent hors du périmètre actuel. Voir PDF_PARSING.md pour l'atelier et les exercices.
